# Personal Portfolio Website 🚀

Welcome to my personal portfolio! This project is a professional representation of my skills, projects, and contact information, built using clean and semantic web technologies.

## 🛠️ Tech Stack
- **HTML5**: Semantic structure for better SEO and accessibility.
- **CSS3**: Custom styling with Flexbox and CSS Grid for a modern, responsive layout.
- **Google Fonts**: Enhanced typography for a professional look.

## 📂 Project Structure
- `index.html` - About Me & Skills section.
- `projects.html` - Showcase of my practice assignments and web projects.
- `contact.html` - A functional contact form layout.
- `css/style.css` - Centralized stylesheet for the entire site.
- `images/` - Contains project screenshots and profile pictures.

## 🌟 Key Features
- **Responsive Design**: Works perfectly on mobile, tablet, and desktop screens.
- **Project Gallery**: A clean grid layout to display my work.
- **Modern UI**: Dark-themed header and smooth hover effects.
